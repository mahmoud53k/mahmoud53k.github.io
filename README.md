# Mahmoud Awd — Personal Page

A simple, responsive contact page for GitHub Pages.

The blurred photo background is saved as `background.jpeg` next to `index.html`; keep both files in the repository root when publishing.

## Publish

1. Create a GitHub repository and upload the files in this folder to its `main` branch.
2. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
3. The included workflow publishes the page after each push to `main`. The live URL will appear under **Settings → Pages** and in the workflow run.

The page is in `index.html`. Update the contact links there if your social accounts change.
